# Research Terminal Skill Standard

## Required Sections

Every skill should include:

- name
- description
- purpose
- inputs
- outputs
- workflow
- principles
- limitations
- future improvements

---

## Design Principles

1. One skill solves one problem.
2. Separate facts from opinions.
3. Explain reasoning clearly.
4. State uncertainty honestly.
5. Prioritize evidence over conclusions.

---

## Output Quality

Every skill should produce:

- Structured output
- Actionable insights
- Confidence assessment
- Clear next steps

---

## Naming Convention

Skill names should follow:

research-<topic>

Examples:

- research-a-share-news
- research-us-stocks
- research-macro
- research-company-analysis
